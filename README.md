# GRC Security Controls Assessment

## Project Overview

This project demonstrates a Governance, Risk, and Compliance (GRC) security controls assessment based on NIST SP 800-53 security standards.

The objective was to evaluate security controls, identify compliance gaps, assess organizational risk exposure, and recommend remediation actions to improve the organization's overall security posture.

---

## Objectives

- Evaluate existing security controls
- Identify compliance deficiencies
- Assess risk impact and likelihood
- Prioritize remediation efforts
- Improve alignment with NIST SP 800-53

---

## Scope

The assessment focused on:

- Access Control (AC)
- Audit and Accountability (AU)
- Risk Assessment (RA)
- Security Assessment and Authorization (CA)
- Configuration Management (CM)

---

## Methodology

1. Security Control Review
2. Gap Analysis
3. Risk Identification
4. Risk Prioritization
5. Remediation Planning
6. Executive Reporting

---

## Key Findings

### Finding 1
Insufficient implementation of least privilege controls.

**Risk:** Unauthorized access to sensitive information.

**Recommendation:** Implement role-based access control (RBAC) and periodic access reviews.

---

### Finding 2
Incomplete audit log monitoring process.

**Risk:** Delayed detection of suspicious activities.

**Recommendation:** Centralize logging and implement continuous monitoring.
